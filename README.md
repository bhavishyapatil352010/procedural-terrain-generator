Procedural Terrain Generator

Weekly Project 01 | Python • NumPy • Matplotlib • Plotly

A procedural terrain generation project built from scratch using Python and NumPy. It generates mathematical landscapes, creates mountains using Gaussian functions, and visualizes terrain as interactive 3D surfaces.

The project explores how numerical data can be transformed into a visual, interactive landscape.

How It Works

1. Numerical Terrain Generation

The terrain is represented using a NumPy 2D array.

Each element represents the elevation at a particular coordinate.

Example:

terrain = np.array([
    [10, 20, 30],
    [20, 80, 40],
    [10, 30, 20]
])

This array acts as a basic heightmap.

2. Terrain Smoothing

A smoothing algorithm modifies neighbouring elevation values to create smoother transitions between terrain points.

This helps reduce abrupt elevation changes.

3. Mountain Generation

Mountains are generated using a Gaussian function.

The mathematical equation is:

[
h = H e^{-\frac{d^2}{2\sigma^2}}
]

Where:

- (h) = generated elevation
- (H) = maximum mountain height
- (d) = distance from the peak
- (\sigma) = controls the mountain's spread

Python implementation:

height = max_height * np.exp(
    -(distance**2) / (2 * sigma**2)
)

4. Combining Terrain

The generated mountain is added to the existing terrain:

final_terrain = terrain + mountain

This produces the final numerical terrain heightmap.

5. 3D Visualization

The terrain heightmap is converted into a 3D surface.

Matplotlib was used for 3D visualization and lighting experiments.

Plotly was then used to create an interactive browser-based visualization.

The resulting HTML allows users to explore the terrain by rotating, zooming and panning.

Installation and Usage

Choose the instructions for your operating system.

Option A: Android — Termux

This project can be executed on Android using Termux and Python.

Step 1 — Update Termux

pkg update && pkg upgrade

Step 2 — Install Python

pkg install python

Step 3 — Install required libraries

pip install numpy matplotlib plotly

Step 4 — Enable shared storage

termux-setup-storage

Allow Termux to access shared storage when Android requests permission.

Step 5 — Navigate to the project directory

cd "$HOME/storage/shared/codes py"

Step 6 — Run the project

python terrianav3.py

Step 7 — Generate the interactive HTML

The program exports the interactive visualization to:

/storage/emulated/0/Download/terrain_3d.html

Step 8 — Open the terrain in a browser

Run:

termux-open /storage/emulated/0/Download/terrain_3d.html

Choose Chrome if Android asks which application to use.

Your interactive 3D terrain is now ready to explore.

---

Option B: Linux / macOS / Windows

Step 1 — Install Python

Install Python 3 on your system.

Step 2 — Install required libraries

python -m pip install numpy matplotlib plotly

Step 3 — Navigate to the project directory

cd path/to/project

Step 4 — Run the project

python terrianav3.py

Step 5 — Open the generated HTML

For desktop use, configure the HTML output path in the script as:

fig.write_html("terrain_3d.html")

The HTML file will be saved in the current working directory.

Open "terrain_3d.html" in Chrome, Firefox or another modern browser.
